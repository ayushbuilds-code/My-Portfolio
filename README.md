## 🎬 Overview

A **cinematic, scroll-driven portfolio** built with pure HTML, CSS, and JavaScript — no frameworks. Features a custom 144-frame scroll animation engine, smooth inertial scrolling, and a fully dark, minimal design system.

> *"Build smarter. Automate faster. Scale further."*

---

## ✨ Features

- **🎞️ Cinematic Frame Animation** — 144 WebP frames play as you scroll, creating a film-like intro experience
- **⚡ Zero Frameworks** — Pure vanilla HTML/CSS/JS, no React, no Vue, no dependencies
- **🌑 Dark Design System** — Deep black backgrounds (`#060609`), crimson accents (`#d91424`), professional typography
- **🃏 Project Showcase** — 4 real projects with live demo links, GitHub links, and animated cards
- **📱 Responsive** — Works across desktop and mobile
- **💬 Direct Contact CTAs** — One-click WhatsApp + Gmail buttons in the contact section
- **🎨 Smooth Animations** — Staggered entrance, hover lift, red rim glow, light sheen sweep effects

## 🛠️ Tech Stack

```

JavaScript     — Frame engine, scroll interpolation, canvas rendering
```

## 🚀 Run Locally

```bash
# Clone the repository
git clone https://github.com/ayushbuilds-code/My-Portfolio.git

# Navigate into the folder
cd My-Portfolio

# Serve locally (Python)
python3 -m http.server 5500

# Open in browser
# http://localhost:5500
```

> ⚠️ Must be served via a local server — opening `index.html` directly won't load the frame images correctly due to browser CORS restrictions.
